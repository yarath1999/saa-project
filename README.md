# 📌 Main Branch (`main`)
---
## 🚀 Hello Team!
Welcome to the `main` branch. This is the **final, stable, and production-ready** version of our project.

### 🛠 Why This Branch Exists
- The `main` branch acts as the **flowing branch** where only verified and approved updates are merged.
- It should always remain stable and ready for deployment.

### 🔥 Rules for This Branch
✅ No direct commits to `main`. All changes must come from `master`.
✅ Only **tested and verified** updates should be merged here.
✅ Always ensure that `main` is stable and working properly.

### 🔄 How We Work with `main`
1. The team pushes new changes to `testing`.
2. After successful testing, updates are merged into `master`.
3. Once verified in `master`, the updates are merged into `main`.

### 🚀 Commands for Updating `main`
To update `main` from `master`, run:
```bash
git checkout main
git merge master
git push origin main
```
